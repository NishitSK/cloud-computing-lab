# Cloud Computing Lab

Two cloud exercises, each in its own folder with its own README.

| Folder | What it is | Platform |
|---|---|---|
| [ec2-apache-website](ec2-apache-website/) | Static website served by Apache HTTP Server (httpd) on an Amazon EC2 instance running Amazon Linux | AWS EC2 |
| [salesforce-pdf-mailer](salesforce-pdf-mailer/) | Apex class that fetches a PDF with an HTTP callout and emails it as an attachment | Salesforce |

Open a folder to see its README for the details, steps and screenshots.
